Private Remote Terminal sync runtime

Generated by scripts/prepare-sync-tools.sh for the target OS and architecture.
bin/: rsync, ssh, ssh-keygen and Windows MSYS2 DLL dependencies.
lib/: Linux shared libraries, excluding the host glibc and dynamic loader.
licenses/: upstream copyright and license notices.
PACKAGES.txt: exact upstream package versions used in this build.
SHA256SUMS: checksums of the bundled executables and libraries.

Corresponding source archives are distributed alongside the release as
sync-tools-sources-<platform>-<architecture>.tar.gz. These tools are separate
executables distributed under their upstream licenses; see licenses/.
Upstream: https://rsync.samba.org/ and https://www.openssh.com/
Windows packages: https://packages.msys2.org/

Building locally:
  Linux: install rsync, openssh-client and patchelf on the build machine.
  Windows: install MSYS2 and its rsync/openssh packages on the build machine;
           set MSYS2_ROOT if MSYS2 is not in C:/msys64.
  npm run tauri build prepares and verifies the runtime automatically.
  Generated binaries are ignored by Git and rebuilt for each target.

Linux binaries use the build runner's glibc baseline (Ubuntu 22.04 x64,
Ubuntu 24.04 arm64). They are not intended for older glibc distributions.
CI also downloads exact corresponding source packages and attaches their
archives to the release. Local source collection is optional via
SYNC_TOOLS_COLLECT_SOURCES=1 and requires deb-src repositories on Linux.
